Installation
============

Requirements
------------

- Python >= 3.10
- numpy >= 1.26.1
- pandas >= 2.2.2
- plotly >= 5.18.0
- scikit-learn >= 1.5.1
- python-dateutil >= 2.8.2
- tqdm >= 4.66.5
- prince >= 0.14.0

Install from PyPI
-----------------

.. code-block:: bash

   pip install dashi

Install from source
-------------------

.. code-block:: bash

   git clone https://github.com/bdslab-upv/dashi.git
   cd dashi
   pip install .
